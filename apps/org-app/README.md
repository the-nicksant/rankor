## �� Sobre o Projeto

**Rankor** é um empreendimento inovador com o objetivo de revolucionar a forma como eventos de luta amadora e semiprofissional são organizados, gerenciados e experienciados. A plataforma visa profissionalizar estruturas digitais para este nicho, oferecendo ferramentas robustas para organizadores, atletas e fãs, desde a criação de eventos e gestão de inscrições até o acompanhamento em tempo real de resultados e perfis de atletas.

Este projeto é a materialização de uma visão para digitalizar e otimizar um segmento que carece de soluções tecnológicas dedicadas, com foco em uma experiência de usuário intuitiva e uma base técnica sólida e escalável.

## ✨ Features (Atuais & Futuras)

Mesmo em estágio inicial, a arquitetura foi concebida para suportar as seguintes funcionalidades:

*   **Gestão Completa de Eventos ✅:**  Cadastro, configuração de categorias de peso, regras e datas.
*   **Inscrição de Atletas (Em Desenvolvimento):** Ferramentas para gerenciamento de participantes e suas informações.
*   **Criação de Cards de Luta (Em Desenvolvimento):** Montagem intuitiva das lutas para cada evento.
*   **Sistema de Resultados (Em Desenvolvimento):** Acompanhamento e registro de resultados de lutas.
*   **Perfis de Usuário (Em Desenvolvimento):** Diferenciação entre organizadores, atletas e fãs, com dashboards personalizados.
*   **Relatórios e Análises (Planejado):** Visualização de dados para otimização de eventos e desempenho de atletas.
